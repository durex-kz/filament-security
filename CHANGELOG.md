# Changelog

## v0.1.2 — 2026-10-21

- Карточка ошибки переделана: сводка (код, статус, сканер, повторы, даты, сообщение, место в коде) и решение — всегда на виду, подробности — на вкладках «Код», «Запрос», «Livewire», «POST-данные», «Стек вызовов», «Повторы»; у полей и вкладок иконки, пустые поля и вкладки не выводятся.
- В карточке появились поля, которых не было: ID записи, «Обновлено», «Отпечаток» (по нему группируются повторы).
- Пользователь-гость и удалённый пользователь подписаны («гость», «#15 (удалён)») вместо прочерка; для «Исправил» без пользователя — «система».
- Исправлены пустые области вокруг «Сообщения», «Решения», стека и POST-данных (white-space: pre-wrap сохранял отступы шаблона); переносы строк теперь через <br>.
- «Копировать» копирует текст без HTML-сущностей (-> вместо -&gt;).
- Заголовок окна просмотра: «Ошибка #3 · 500» вместо «Просмотр Ошибка».

## v0.1.1 — 2026-10-21

- Журнал ошибок: длинное «Сообщение» в карточке ошибки переносится, в том числе внутри длинных слов (SQL, пути, адреса).
- Журнал ошибок: все колонки таблицы можно скрыть через «Колонки», включая колонки, добавленные проектом через `errorLogUserColumns()`.

## v0.1.0 — 2026-10-20
